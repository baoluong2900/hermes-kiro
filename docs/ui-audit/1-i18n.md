# UI Audit 1 — i18n Consistency (Kiro-Go admin)

Scope: `web/index.html`, `web/app.js`, `web/locales/en.json`, `web/locales/zh.json`.
Method: `read_file` + `search_files` only. No source files modified.
Each locale file = 600 keys, in identical order (601 lines incl. 1 blank at line 4).

---

## CONFIRMED issues (verifiable from files)

### C1 — Entire "External API / Model config" card bypasses i18n (hardcoded Vietnamese)
`web/index.html` lines 346–385. All human-readable text is hardcoded; no `data-i18n*`:

| Line | Hardcoded string | Element |
|------|------------------|---------|
| 348 | `Cấu hình Model & Priority Call URL` | card title |
| 352 | `Dùng External API thay cho Account List Kiro` | toggle label |
| 354 | `Bật: gọi URL ngoài trước. Tắt: dùng Account List Kiro như cũ, không xoá hay tắt account nào.` | hint |
| 358 | `ANTHROPIC_BASE_URL (URL API ngoài)` | field label |
| 362 | `ANTHROPIC_API_KEY / Auth Token` | field label |

| 382 | `Lưu Cấu Hình Model & API` | save button |

These render identically in both EN and ZH (no translation possible).

### C2 — `sourceSwitcher` title hardcoded Vietnamese
`web/index.html:101` — `title="Quản lý nguồn dữ liệu (Data source)"`. No `data-i18n-title`; never localized.

### C3 — Referenced key missing from both locales: `builderid.userCode`
`web/app.js:2895` — `t("builderid.userCode") || "User Code"`.
Not present in `en.json` or `zh.json` (locale has only `builderid.{startLogin,verifyCode,verifyUrl,open,waiting,success}`). The `|| "User Code"` fallback masks it to English in both languages; without the fallback it would render blank. CONFIRMED missing; impact mitigated by fallback.

### C4 — ZH locale value polluted with Vietnamese + semantic mismatch
`web/locales/zh.json:523` — `"apiKeys.actionExpire": "设为超额 (Hết hạn)"`.
Problems: (a) ZH string embeds Vietnamese `(Hết hạn)`; (b) EN is `"Mark Expired"` (en.json:523) while ZH `设为超额` means "set as overage" — divergent meaning for the same key.

## Checks that came back CLEAN

- **Key parity EN↔ZH:** both files 600 keys, same keys in same order. No key present in one and missing from the other. CONFIRMED.
- **Empty-string values:** none found in either locale. CONFIRMED.
- **Non-fallback `t()` keys missing from locales:** spot-checked all fallback-guarded `t()` calls (the author's hints to likely-missing keys); only `builderid.userCode` (C3) is absent. A full byte-level diff of every `data-i18n*` / `t()` reference against the key set was not exhaustively enumerated by hand — remaining non-guarded references all resolved to existing keys on inspection.

3. C2 — add `data-i18n-title` for `sourceSwitcher`.
4. C3 — add `builderid.userCode` to both locales.
5. S1/S2 — move leaked literals into locale keys.
